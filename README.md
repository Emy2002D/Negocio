# 🍰 Postres Galicia - Vue 3 + Vite

Bienvenido al repositorio oficial de **Postres Galicia**, una aplicación web creada con Vue 3 + Vite que combina desarrollo moderno con sabor tradicional. Este proyecto tiene como objetivo ofrecer una experiencia visual atractiva y responsiva para presentar menús, gestionar contacto, integrar delivery y mostrar al creador detrás del concepto.

## 🚀 Tecnologías utilizadas

- **Vue 3** con `<script setup>`
- **Vite** como bundler ultrarrápido
- **Bootstrap 5.3** para diseño responsivo y componentes estilizados
- **HTML + CSS inline** con utilidades de Bootstrap
- **Vue SFCs (Single File Components)**

## 🎨 Características principales

- ✅ Navbar responsiva con animaciones
- ✅ Hero destacado con llamada a la acción
- ✅ Carrusel automático para frases/inspiración gastronómica
- ✅ Tarjetas de productos más vendidos
- ✅ Sección de delivery con integración visual (Didi, Uber Eats, Rappi)
- ✅ Sección de contacto con mapa embebido
- ✅ Perfil del creador con fotografía, historia y redes sociales (Instagram, LinkedIn, GitHub)
- ✅ Footer con íconos sociales y accesos rápidos
